07 / OPERATOR MANUAL
Before you connect a repository.
What does DOCAGENT do?
DOCAGENT is a proposed AI documentation maintenance layer for open-source projects. It is designed to connect code changes to the documentation, examples and translations that need attention.
Does this version process real repositories?
This standalone frontend uses a prepared example workspace. Repository monitoring, AI generation and pull request creation require backend services and an authorized Git integration.
Will agents overwrite project files automatically?
The intended workflow produces review artifacts. Maintainers inspect the diff and approve changes before anything is merged upstream.
What does connecting a wallet do here?
It requests the public address from an installed Phantom wallet. The preview does not request a signature, move tokens or unlock a paid service.
Is there an official contract address?
No contract address has been provided for this version. Trading links will remain unavailable until an official address is confirmed.
How is generated documentation checked?
The planned pipeline maps drafts to source symbols, checks examples and flags uncertainty. Human review remains necessary; generated explanations are not guaranteed to be correct.
